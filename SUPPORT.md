# Support

This repository is a small example project for practicing a clear pull-request workflow.

## Where to ask

- **Bug reports:** use the Bug Report issue form.
- **Feature ideas:** use the Feature Request issue form.
- **How-to questions:** open a discussion in an existing issue when it is relevant, or create a new issue with the `question` label if available.
- **Security concerns:** follow [SECURITY.md](SECURITY.md) and do not publish sensitive details in an issue.

## Before opening an issue

1. Search existing issues for the same question or problem.
2. Include the relevant context and exact steps to reproduce a problem.
3. Keep one issue focused on one topic.
