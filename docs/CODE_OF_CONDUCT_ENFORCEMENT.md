# Code of Conduct Enforcement

Community concerns should be handled promptly, fairly, and with respect for everyone involved.

## Response process

1. Review the report and gather relevant context privately where appropriate.
2. Consider the impact and whether the behavior conflicts with the repository's community guidelines.
3. Choose a proportionate response, such as clarification, a request to edit a comment, a warning, or restricting participation when necessary.
4. Explain the decision to the people involved without disclosing private information.
5. Record any follow-up needed to prevent recurrence.

## Principles

- Apply expectations consistently.
- Protect reporters from retaliation.
- Keep private details out of public discussions.
- Escalate threats or security concerns through appropriate private channels.
