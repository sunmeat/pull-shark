# Issue Label Conventions

Use labels to communicate the type and current status of an issue, not to replace a clear title or description.

## Suggested types

- `bug`: behavior that does not work as expected
- `enhancement`: a proposed improvement
- `documentation`: a documentation correction or addition
- `question`: a request for clarification
- `dependencies`: a package or action update

## Suggested status labels

- `needs-triage`: not yet reviewed
- `needs-info`: more information is required
- `blocked`: work depends on another decision or change

Use the labels already configured in the repository. Avoid creating near-duplicates, and remove temporary status labels when they no longer apply.
