# Accessibility Guidance

Accessible documentation is easier for more people to use.

- Use headings in a logical hierarchy.
- Write meaningful link text that makes sense out of context.
- Provide useful alternative text when images convey information.
- Do not rely on color alone to communicate a status or distinction.
- Use descriptive names for controls and avoid unexplained abbreviations.
- Keep tables simple and give them clear headers.
- Prefer plain language and explain specialized terms.

When adding a visual example, include a text explanation of the information that matters. Review these points when changing the README, templates, or workflow documentation.
