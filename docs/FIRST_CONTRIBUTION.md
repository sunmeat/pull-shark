# First Contribution Guide

Welcome! A small, well-scoped change is a good way to learn the repository's workflow.

1. Read the [contribution guide](../CONTRIBUTING.md) and [community guidelines](../CODE_OF_CONDUCT.md).
2. Search open and closed issues to see whether the topic is already being discussed.
3. For a substantial idea, open an issue before writing a large patch.
4. Create a branch with a descriptive name.
5. Make one focused change and update relevant documentation.
6. Run the checks available for your change.
7. Open a pull request using the repository template and explain how you validated it.

If you are unsure about scope, ask a concise question before investing in a large implementation.
