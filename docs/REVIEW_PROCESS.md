# Review Process

## Prepare a change

Create a focused branch and keep the diff limited to one purpose. Use a descriptive title and explain the motivation in the pull request description.

## Review the diff

Check the changed files, look for accidental edits, and confirm that the documentation matches the actual behavior. Run available automated checks and address any failures before merging.

## Merge

Resolve feedback, confirm the change is ready, and use the repository's normal merge method. After merging, remove the branch when it is no longer needed.
