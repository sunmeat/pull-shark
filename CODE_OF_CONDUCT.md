# Community Guidelines

## Our expectations

We aim to keep collaboration respectful, welcoming, and focused on the work.

- Be considerate and constructive when discussing ideas or reviewing changes.
- Critique code and proposals, not people.
- Explain disagreements clearly and assume good intent while staying open to evidence.
- Respect privacy. Do not publish personal information or credentials.
- Keep discussions relevant to the project.

## Reporting a concern

If behavior makes participation difficult or unsafe, contact the repository owner privately through a channel listed on their GitHub profile. Include relevant context and links, while avoiding unnecessary personal information.

## Scope

These guidelines apply to project issues, pull requests, reviews, and other spaces used for project collaboration.
