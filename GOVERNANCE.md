# Governance

## Project ownership

Pull Shark is maintained by [@sunmeat](https://github.com/sunmeat), who is responsible for the repository's direction, maintenance, releases, and final decisions.

## How decisions are made

The project favors small, explainable changes that improve its purpose as a practical example of a healthy GitHub pull-request workflow.

- Anyone may propose an improvement through an issue or pull request.
- Discussion should focus on the problem, available options, and trade-offs.
- Changes should be consistent with the repository's scope and documented standards.
- The maintainer makes the final decision after considering relevant feedback.
- Significant decisions should be recorded using the decision-record guidance in the repository.

## Contributions and review

Contributors are welcome to suggest corrections, documentation improvements, workflow examples, and maintenance changes. A pull request is a proposal, not a guarantee of acceptance. Review may request clarification, revisions, or a narrower scope.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution process and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for community expectations.

## Changes to governance

Governance changes should be proposed in a pull request, explained in its description, and reviewed before merging. This document may evolve as the repository's needs change.
