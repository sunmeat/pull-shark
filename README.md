# Pull Shark

A small repository for practicing a healthy GitHub pull-request workflow: focused changes, clear descriptions, automated checks, and maintainable project documentation.

## Workflow

1. Create a branch for one focused change.
2. Open a pull request describing the motivation and impact.
3. Run the available checks and review the diff.
4. Merge only when the change is ready.

## Repository standards

See [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidance, the pull request template for review details, and [docs/WORKFLOW.md](docs/WORKFLOW.md) for the intended workflow.

## Automation

Markdown files are checked by GitHub Actions. Dependabot keeps GitHub Actions dependencies up to date.
