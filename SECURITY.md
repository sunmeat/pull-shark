# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Instead, use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository owner privately through the contact options on their GitHub profile.

Include the affected file or component, steps to reproduce the issue, potential impact, and any suggested mitigation. Please allow reasonable time for investigation before publicly disclosing a vulnerability.

## Scope

This repository is a small project for practicing GitHub workflows. Reports should focus on issues that could affect repository users, maintainers, or its automation.
